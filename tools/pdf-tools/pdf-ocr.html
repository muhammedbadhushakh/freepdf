How to use PDF OCR

  1. Click the upload area and choose your file, or drag and drop it in.
  2. PDF OCR processes the file directly in your browser using client-side code — nothing is uploaded to a server.

Yes. PDF OCR runs entirely in your browser using client-side JavaScript, so your file is never uploaded to a server or stored anywhere.
