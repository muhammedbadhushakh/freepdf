How to use Crop PDF

  1. Click the upload area and choose your file, or drag and drop it in.
  2. Crop PDF processes the file directly in your browser using client-side code — nothing is uploaded to a server.
  3. Review the result, then click Download to save it to your device.

Yes, Crop PDF is completely free, with no sign-up, watermark, or software install required.

Is my file safe when I use Crop PDF?

Yes. Crop PDF runs entirely in your browser using client-side JavaScript, so your file is never uploaded to a server or stored anywhere.

Does Crop PDF work on mobile?

Yes, Crop PDF works in any modern browser on desktop, phone, or tablet — no app needed.
