How to use Redact PDF

  1. Click the upload area and choose your file, or drag and drop it in.
  2. Redact PDF processes the file directly in your browser using client-side code — nothing is uploaded to a server.
  3. Review the result, then click Download to save it to your device.

Frequently Asked Questions

Is Redact PDF free to use?

Yes, Redact PDF is completely free, with no sign-up, watermark, or software install required.

Is my file safe when I use Redact PDF?

Yes. Redact PDF runs entirely in your browser using client-side JavaScript, so your file is never uploaded to a server or stored anywhere.

Does Redact PDF work on mobile?

Yes, Redact PDF works in any modern browser on desktop, phone, or tablet — no app needed.
